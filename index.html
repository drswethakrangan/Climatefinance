How to read this dashboard. A = Agriculture, I = Industries, S = Services. The sector prefix has been separated from the climate pathway name. Scenario pathways are conditional projections, not forecasts. GDP index sets each selected series' T+0 value to 100. Annualised growth is calculated from T+0 to T+20. The dashboard does not add the three sectors together: aggregation should only be done after confirming that the sector series are mutually exclusive, exhaustive, and measured on a consistent basis.
Data interpretation note. The uploaded file contains state, sector-coded scenario, and GDP_T+0 through GDP_T+20 values. Units, price basis, and the meaning of the T+0 calendar year are not specified in the file; confirm these in the dataset documentation before presenting absolute GDP values as currency or comparing them with published state GSDP.
